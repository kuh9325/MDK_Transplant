Validated on all 46 tag-family files in BUILD_A + the mdkfopen-path stem check (`FUN_0042fae8`). Phase 3C: `.SNI` interior directory PROVEN — `u32 count @0x14` + N×24-byte records `{name[12], u32 @+0x0c (UNKNOWN), blobOff @+0x10 (relative to file offset 4), byteSize @+0x14}`; payloads tile `[dirEnd, size−12)`, 4-aligned; `K_*` sentinel records (`field==size==0xffffffff`) carry position markers. Phase 3D: `.MTI` interior directory PROVEN — same count@0x14 + 24-stride framing but `name[8]` + `{flags@+0x08, u32@+0x0c, u32@+0x10, blobOff@+0x14}`; `flags==0xffffffff` = index record (only `+0x0c` read); `flags & 0x30000` select 4- vs 8-byte u16 payload header; the original's own strings call it the material table (`loadmats.c`, `matdef`, `Texture %s not in material list`). Phase 3E: `.MTO` interior directory PROVEN — `u32 count @0x14` + N×12-byte records `{name[8], fileAbsOff @+0x08}` indexing self-contained "overlay" blocks; each block's u32 is its self-inclusive byte length (streamed from off+4 in ≤0x8000 chunks), and each block embeds a full tagged `.MAT` image at +0x10 (parsed by the shared MTI parser `FUN_0041a1e0`) plus region A `{countA,countB,countC}` record arrays (countB = overlay-alien references resolved by `FUN_00403720`; countC ≤ 0x10 = overlay-sound records — `Too many overlay sounds`), a fixed 0x150-byte region B, and the nested region C counted arrays (10/44/36/12-byte records) walked by `FUN_00419ee0`; the original's own strings name the subsystem "overlay" (`overlay` alloc tag, `No overlay data for %s`). Region/payload semantics UNKNOWN. Phase 3F: `.CMI` interior PROVEN — four counted variable-length tables of `{u8 len, name[len incl NUL], u32 image-relative value}` records followed by a bounded data region; consumed at traversal load for the original's "enemy table" copy and per-arena name lookups; data-region semantics UNKNOWN. Phase 3G: `.DTI` interior PROVEN — five image-relative TOC offsets @0x14 tiling sections: s0 params (0x74 = 29 u32s; initial arena, view state, fill bytes, grid dims `cols−4`/`rows`, second-plane flag, ramp matrix), s1 `{count, count×24B}` keyed records (debug-command lookups; the original reads word[6] into the next record — observed boundary-crossing quirk), s2 `{count, count×16B {name[8], payloadImgOff, scalar}}` = the original's "arena" table (`arena %s not found`) with tiled `{count, count×36B}` typed payloads (2=HotGen, 4=HotPick, 6=connect — paired by ID+coords+side then rewritten to partner arena indices; types 1/3/5/7/8/9 UNKNOWN), s3 `{count, 768B RGB}` = palette source, s4 = `(cols+4)×rows` byte grid, 1–2 planes = backdrop image.
